# Brawlmates — Telegram Mini App для игроков Brawl Stars

Название пишется именно так: `Brawlmates` (одно слово, с большой буквы).
В коде и URL — `brawlmates`.

## О проекте
Мини-приложение в Telegram, где игрок Brawl Stars привязывает свой игровой аккаунт,
видит красивый профиль со статистикой и (позже) находит тиммейтов.

Проект делает начинающий разработчик вместе с Claude Code. Поэтому:
- перед любой заметной правкой коротко объясняй план простыми словами;
- после выполнения задачи кратко поясни, что изменилось и как это проверить;
- предпочитай простые и понятные решения хитрым; не добавляй зависимости без нужды;
- если задача размытая — задай 1–2 уточняющих вопроса, а не угадывай.

## Этапы
1. **Профиль-трекер** (готово): вход через Telegram, привязка тега с проверкой,
   карточка игрока, список бравлеров, история боёв и график трофеев.
2. **Поделиться профилем + поиск тиммейтов (LFG)** (текущий): публичные заявки
   «ищу пару/тройку» с фильтрами. Правила — в разделе «LFG» ниже.
3. **Команды и друзья** — только после того, как 1–2 реально используются.

## Стек
- Next.js (App Router) + TypeScript, деплой на Vercel
- Tailwind CSS; цвета берём из темы Telegram (`themeParams`), поддержка светлой и тёмной темы
- `@telegram-apps/sdk-react` на клиенте
- Postgres (Neon или Supabase через Vercel Marketplace), ORM — Drizzle
- Бот: grammY, вебхук на `/api/bot`
- Фоновые задачи: Vercel Cron → `/api/cron/*`

## Переменные окружения
- `TELEGRAM_BOT_TOKEN` — токен бота
- `BS_API_TOKEN` — ключ Brawl Stars API
- `BS_API_BASE_URL` — базовый URL API (официальный или прокси со статическим IP)
- `DATABASE_URL`
- `CRON_SECRET` — проверка, что крон вызывает именно Vercel
- `ADMIN_IDS` — Telegram ID модераторов через запятую (доступ к `/admin`)

Никогда не коммить `.env*` и не выводи секреты в логи.

## Правила работы с Brawl Stars API
- Все запросы к API — только на сервере, никогда из браузера (ключ привязан к IP).
- Теги игроков начинаются с `#`; в URL кодировать как `%23`. Нормализовать: верхний регистр, `O` → `0`.
- Кешировать ответы профиля минимум на 5 минут, чтобы не упираться в лимиты.
- Battlelog отдаёт только последние ~25 боёв → крон регулярно сохраняет новые бои в БД,
  дубликаты отсекаем по (тег игрока + `battleTime`).
- Обрабатывать ошибки API (404 — нет такого тега, 429 — лимит, 503 — техработы) понятными сообщениями.

## Авторизация
- Пользователь = Telegram-аккаунт. На сервере всегда проверяем подпись `initData`
  (HMAC с токеном бота) и не доверяем данным с клиента без проверки.
- Привязка тега с подтверждением владения: сервер просит поставить в игре определённую
  иконку профиля из базовых, затем сверяет `icon.id` через API. Иконку можно вернуть сразу после.

## Безопасность (важно: многие игроки — дети)
- Никаких личных сообщений между пользователями внутри приложения.
- Профиль показывает только игровые данные и ник; Telegram-username — только если
  пользователь сам включил «показывать, как со мной связаться» (по умолчанию выключено).
- У любого пользовательского контента (заявки LFG, описания) — кнопка «пожаловаться»;
  у пользователя — возможность скрыть/заблокировать другого.
- Храним минимум данных; пользователь может удалить аккаунт и все свои данные одной кнопкой.

## LFG (поиск тиммейтов)
- Заявка собирается из готовых вариантов: режим, бравлер(ы), диапазон трофеев, язык,
  сколько игроков нужно. Свободный текст — необязательный, до 80 символов, с фильтром мата
  и ссылок.
- Заявка живёт 2 часа, потом автоматически скрывается. У одного игрока — максимум 1 активная.
- Основной способ связаться — **добавить в друзья в самой игре**: кнопка «Скопировать тег»
  и инструкция. Telegram-контакт показывается только если автор сам включил это в настройках.
- Отклик «Я в деле» уведомляет автора через бота, но не раскрывает Telegram откликнувшегося
  без его согласия.
- Кнопки «Пожаловаться» и «Скрыть этого игрока» на каждой заявке; лимит — не больше
  5 заявок в сутки и 20 откликов в час на пользователя.
